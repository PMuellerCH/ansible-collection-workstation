# swisstopo.workstation.gh

Installs the GitHub CLI (`gh`) via apt and holds it at the pinned version.

## Variables

| Variable | Default | Description |
| --- | --- | --- |
| `gh_version` | `2.45.0-1ubuntu0.3` | Exact apt package version of `gh` to install |

## Platforms

| OS | Tested |
| --- | --- |
| Ubuntu 24.04 | yes |
